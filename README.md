# sentiment-analysis
# Features

Analyze English text sentiment

Classify text as Positive or Negative

Display the model's prediction and confidence score

Simple interactive interface with Streamlit

# Tech Stack
Python, Streamlit, Hugging Face Transformers, Pre-trained Sentiment Analysis Model

# How It Works
Enter English Text -> Transformer Model -> Sentiment Classification -> Positive / Negative

The application uses a pre-trained Transformer model through the Hugging Face pipeline API. No model is trained from scratch.
